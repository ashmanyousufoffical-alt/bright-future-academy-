# Bright Future Academy

A responsive academy website built with HTML, CSS, and JavaScript.

## Features
- Responsive desktop and mobile layout
- Student admission eligibility checker
- Course fee calculator with 5% discount for 3–5 months and 10% discount for 6+ months
- Basic form validation
- Light/dark mode toggle

## Run locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example, `bright-future-academy`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. After deployment, GitHub shows your live site URL on the Pages settings screen.

This is a front-end student project. Admission results are preliminary and are not sent to a server.
